## 🚀 About Me

I'm a Salesforce Developer passionate about transforming business requirements into reliable, maintainable, and scalable Salesforce solutions.

- ☁️ Developing Salesforce applications using **Apex, Triggers, and Lightning Web Components**.
- ⚙️ Automating business processes with **Salesforce Flow, Queueable Apex, and Scheduled Apex**.
- 🔗 Integrating Salesforce with external systems using **REST APIs, Apex Callouts, and Named Credentials**.
- 🤖 Exploring **Agentforce, Prompt Builder, and AI-powered Salesforce applications**.
- 🔐 Building secure access-management solutions using **Permission Sets and Permission Set Assignments**.
- 📦 Working with **Salesforce DX, CLI, unlocked packages, Git, and Copado**.
- 🧪 Focused on bulk-safe code, test coverage, maintainability, and secure development practices.
- 🌱 Continuously learning Salesforce architecture, AI, and DevOps.
